MailFlow — это веб-приложение на Django для управления email-рассылками.
Проект реализует полноценную систему работы с клиентами, сообщениями и рассылками с разграничением прав доступа, отправкой писем через SMTP, логированием попыток доставки и системой статистики.

Реализованы:

кастомная модель пользователя (авторизация по email),

ролевая модель доступа (пользователь / менеджер),

серверное кеширование,

отправка рассылки через интерфейс и через CLI-команду,

хранение истории попыток отправки.

Проект построен по принципам production-архитектуры Django.\

🛠 Установка проекта
1️⃣ Клонировать репозиторий
git clone https://github.com/your_username/mailflow.git
cd mailflow

2️⃣ Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

3️⃣ Установить зависимости
pip install -r requirements.txt

4️⃣ Создать файл .env

Создать файл .env в корне проекта:

SECRET_KEY=your_secret_key
DEBUG=True

DB_NAME=mailflow
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

EMAIL_HOST_USER=your_email@yandex.ru
EMAIL_HOST_PASSWORD=your_app_password

5️⃣ Применить миграции
python manage.py migrate

6️⃣ Создать суперпользователя
python manage.py createsuperuser

7️⃣ Запустить сервер
python manage.py runserver


Перейти в браузере:

http://127.0.0.1:8000
